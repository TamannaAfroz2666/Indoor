# Indoor

A modern indoor turf booking platform, built with Next.js, NestJS, PostgreSQL, and GraphQL.

## ✨ Features

- Venue discovery
- Search by location
- Sports filtering
- Turf details
- Slot availability
- Booking system
- User authentication
- Responsive UI

## 🛠️ Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- Redux Toolkit

### Backend
- NestJS
- PostgreSQL
- Prisma
- GraphQL
- REST API
- JWT Authentication
